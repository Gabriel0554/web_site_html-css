# 🌐 Projeto Web - HTML & CSS

Este projeto foi desenvolvido como atividade acadêmica da faculdade UDF com o objetivo de aplicar os conceitos fundamentais de desenvolvimento web utilizando **HTML5** e **CSS3**.

## 📚 Sobre o Projeto

O site foi criado utilizando apenas estruturas de HTML e CSS, focando na construção de páginas, organização semântica do conteúdo e estilização visual. Durante o desenvolvimento, foram aplicados conhecimentos essenciais para a criação de interfaces web responsivas e bem estruturadas.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3

## 🎯 Objetivos de Aprendizagem

- Estruturar páginas utilizando HTML semântico;
- Aplicar estilos e layouts com CSS;
- Organizar conteúdos de forma clara e intuitiva;
- Desenvolver boas práticas de desenvolvimento front-end;
- Compreender os fundamentos da criação de sites.
